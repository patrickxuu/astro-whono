你好，欢迎来到这里

你可以叫我 Patrick 。如果你恰好在此驻足听我吐露心声，我确信这是一段伟大友情的开始。

主包个人认为，自己是个爱好十分广泛且向往自由的 INFJ，从编程 Coding 到四处旅行（Maybe like 数字游民？反正我超爱🥰），从铁路交通爱好者到城市规划学习者，热爱科技、热爱 Apple，喜欢音乐、喜欢播客，爱听彩虹、五月天，也爱玩欧卡、城市天际线、我的世界。至少你总能在你的领域内找到一些我曾经涉足甚至喜爱过的痕迹。而有一点这样的共同话题，何尝不是我们在这繁杂世间的一丝欣喜呢。

如你所见，这可能是我的第三个正式使用的博客站点。我认为自己还是有点强迫症在身上的，不然也不会尝试一个个不同架构的博客框架、不会在换了好几次邮箱之后丢失了原来的 GitHub 账号（庆幸自己的代码做了好多离线备份，还可以 Fork 回来几个自己公开的仓库），甚至自己现在还专门留了一个 Apple 备忘录叫“强迫症会懂”。

（好了，主包现在又在纠结这里英文词前后加不加空格的问题了🤔）。

个人认为博客站点是需要回归文字本身的，否则像我这样的人一定会为了封面图片、主页搭配而焦头烂额。这也是我一直不敢使用 Notion 的原因（曾经为了找到喜欢的 Markdown 编辑器还尝试过 Typora、语雀、Obsidian、熊掌记），当附加内容多了，我能够留给文字与思考的 priority 很难不会下降。非常幸运在无意间找到了 [astro-whono](https://github.com/cxro/astro-whono) 这个主题（终于是掉进 Astro 的坑里了），随笔、絮语、小记的设计真切戳中了我需要朋友圈图文形式与长篇叙事的需求。后续或许还会出个博客装修的连载。

本来想在这里再附上一份个人简历。不过以我现在的体量，来到这里的你们应该不是专门为了我的简历而来哈哈哈哈哈（我会努力做到让你们主动访问简历的 ~ ）。但还是先附上个在线版本吧：[CV_zh](https://www.patrickxuu.top/archive/patrickxuu-cv-zh/)。

以我曾经第一个博客站点的结尾句开始吧：派大星，我们一起去抓水母吧 ~
